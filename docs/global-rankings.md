# Worldwide Rankings\n\nThe public leaderboard displays only the top 20 creators/publishers and top 20 advertisers/marketers.\n\nCreator ranking includes verified social platform views deduplicated by post, verified tracking-link clicks, verified publisher video views/clicks and verified delivery events. Only verified creator/publisher profiles are included; risk-reviewed or blocked events are excluded.\n\nAdvertiser ranking uses confirmed funding payments (held or released) and the number of campaigns with confirmed funding. It does not rank advertisers by follower count or impressions.\n
